# Teşvik Atlası

2009–2023 arasında Resmi Gazete'de ilan edilen 107 bin yatırım teşvik belgesinde firma, il ve sektör bazında anında arama yapan, telefona kurulabilen web uygulaması.

- Tüm arama cihazda yapılır; sunucu gerekmez.
- İlk açılıştan sonra internetsiz çalışır.
- Veri: `data.json.gz` (Resmi Gazete ilanlarından derlenmiş liste).
